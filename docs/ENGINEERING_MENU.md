# PEARL Engineering Menu & Advanced Features

## Overview
The Engineering Menu provides advanced configuration, diagnostics, and calibration for the PEARL system. Access is protected by a password and requires a triple-click on the menu encoder.

## Accessing the Engineering Menu
- **Entry:** Triple-click the menu encoder rapidly.
- **Password:** Enter the 4-digit password (default: 1234). Password can be changed in Security settings.
- **Timeout:** Menu auto-exits after inactivity for security.

## Menu Structure
- **Calibrate:** Step-by-step calibration with editable positions, review/undo before saving.
- **Set Params:**
  - Encoder Settings: Resolution, scale, direction, velocity filter
  - Display Settings: Contrast, backlight
  - System Settings: Timeouts, debug, error thresholds (future)
  - Security: Change password, reset password
  - Back: Return to main menu
- **Diagnostics:** Live encoder value, error count, FIFO usage, system status
- **About:** Firmware version, build date, author
- **Exit:** Return to user menu

## Key Features
- **Confirmation Dialogs:** For Factory Reset, Save & Exit, Calibration
- **Parameter Grouping:** Logical grouping and descriptions in Set Params
- **Diagnostics:** Real-time feedback for troubleshooting
- **Calibration:** User-driven, editable position entry, review/undo before saving
- **Password Management:** Change, show/hide, reset to default
- **Timeouts:** Auto-exit after inactivity
- **Help/Info:** Contextual help and About screens
- **Persistent Storage Feedback:** User feedback on save/flash operations

## Usage Tips
- Use the encoder to navigate and edit values
- Press Enter to select, Back to return/cancel
- For help, select the '?' or hold the encoder (future)

## Security
- Change your password after first use
- Use the reset option if you forget your password (requires confirmation)
