# Copilot Tracking Directory

This directory is used to track detailed task plans, implementation steps, and change histories for Copilot-driven development.

## Example Structure
- `plan.md` — High-level plan or roadmap for a feature or release.
- `details/` — Folder for detailed breakdowns of each task (one file per task).
- `changes/` — Folder for documenting changes, decisions, or context for each tracked task.

You can add, rename, or organize files as needed to fit your workflow.
